# Tutoriais Metodos computacionais para fisica
Esse repositório tem alguns tutorias de metodos simples, porém bastante gerais para resolver problemas de forma numérica, bem como representar graficamente de diferentes jeitos. A principal bibliografia utilizada é o Livro do Mark Neumann com capítulos inicias disponível gratuitamente, pelo autor, no link: https://public.websites.umich.edu/~mejn/cp2/chapters.html
